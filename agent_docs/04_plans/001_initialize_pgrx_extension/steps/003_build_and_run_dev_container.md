# Step: 003 - Verify Extension Load

## Goal
Build the extension inside the container, install it into the local PG paths, and verify it loads.

## Tasks
- [ ] Run `cargo pgrx install` inside the container.
- [ ] Connect to `psql` and run `CREATE EXTENSION stat_pg;`.
- [ ] Run the default hello function generated by `pgrx` to confirm successful invocation.

## Verification
- Confirm that the hello function returns the expected greeting.
